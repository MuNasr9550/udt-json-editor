# UDT JSON Editor

A lightweight, browser-based editor for structured JSON files. It displays arrays of objects as filterable, sortable tables, making large configuration files easier to inspect and update. It also includes tools for editing UDT configuration exports.

## Features

- Open JSON files from your computer or drag and drop them into the page.
- Browse top-level and nested arrays of objects in tables.
- Search and filter rows, sort columns, group rows, and choose which columns to show.
- Edit cells inline or edit rows and sections as raw JSON.
- Apply bulk edits, duplicate rows, and delete rows.
- Undo and redo changes, then download the edited JSON file.
- Export the current table view to CSV.
- For supported UDT files, create templates, derived templates, instances, and members; edit instance overrides; and change member data types.

## Run Locally

No installation or build step is required. Clone or download this repository and open `index.html` in a modern web browser. Select **Open JSON…** or drop a `.json` file onto the page.
